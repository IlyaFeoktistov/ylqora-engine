# Редактор

[English version](editor.md)

Редактор - приложение на движке: менеджер проектов, правка сцен и Play.
Логика живёт в `editor/src` без ImGui, отрисовка - в `editor/ui`.

Пометки статуса: см. [README](README.ru.md).

## Части

- `EditorApp` собирает редактор: тему, настройки, действия, панели.
- `EditorSession` держит открытый проект, документ сцены, Play и выделение.
- `SceneDocument` - редактируемая сцена, её файл и история правок.
- `PlayMode` - копия сцены для Play со своими службами.
- Панели в `editor/ui` каждый кадр получают `EditorContext`.

## Разделение [next]

- Правка (создание и удаление узлов, компоненты, свойства, трансформы,
  отмена и повтор) уходит из `EditorSession` в `SceneEditing`, который меняет
  текущую сцену через команды.
- Главная сцена проекта уходит в настройки проекта, раздел General (см.
  [настройки проекта](project-settings.ru.md)).
- Открытие и закрытие проекта (службы, оповещение панелей, список проектов)
  уходит из `EditorApp` в сессию; заголовок окна собирает функция без ImGui.
- `EditorContext` даёт панелям `EditorHost` вместо всего `Application`:
  рендерер, диалог выбора папки, язык, выход, перенос курсора.
- Имя ресурса в инспекторе (встроенный меш, путь в проекте) определяется без
  ImGui, в `editor/src`.
