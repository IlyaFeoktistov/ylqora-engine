# Редактор кода [planned, after MVP]

[English version](code-editor.md)

Скрипты пишутся в самом редакторе: вкладка "Скрипты" в нижней панели, рядом
с "Файлами". Появляется вместе с Luau; позже в той же вкладке правятся
шейдеры.

Пометки статуса: см. [README](README.ru.md).

## Вкладка

- В нижней панели вкладки "Файлы" и "Скрипты", позже "Шейдеры". Двойной
  щелчок по файлу `.luau` в "Файлах" открывает его в "Скриптах".
- Каждый открытый файл - своя вкладка, изменённый помечен `*`. Ctrl+S
  сохраняет; сохранение скрипта перезагружает модуль Luau (см.
  [скрипты](scripting.ru.md)).
- Подсветка синтаксиса, автодополнение, подсказки при наведении, ошибки
  подчёркнуты в тексте и перечислены под ним, переход к определению.
- Вместо этого в настройках редактора можно выбрать внешний редактор (VS
  Code и подобные); тогда вкладка только открывает файл в нём.

## Где живёт логика

Как и во всём редакторе, логика отдельно от ImGui:

- `TextDocument`: текст одного файла, курсор и выделение, история правок,
  загрузка, сохранение, признак изменения.
- Язык: расширения файлов, подсветчик, который делит строку на токены
  (ключевое слово, строка, число, комментарий, имя), и языковой сервер, если
  он есть. Цвета токенов берутся из темы редактора.
- `LanguageClient`: общается с языковым сервером по Language Server Protocol
  (stdio): дополнение, подсказки, диагностика, определения.
- Виджет в `editor/ui` только рисует `TextDocument` и передаёт ему клавиши и
  мышь.

## Подсказки для Luau

- Языковой сервер - [luau-lsp](https://github.com/JohnnyMorganz/luau-lsp)
  (MIT), один процесс на открытый проект. Без него подсветка работает, нет
  только подсказок.
- Типы движка он узнаёт из файла определений, который генерируется из
  реестра типов (свойства и методы, см. [рефлексию](reflection.ru.md)). Файл
  пишется в проект при открытии и после каждой перезагрузки модуля, так что
  в подсказках есть и собственные типы игры.

## Шейдеры позже

- Тот же `TextDocument` и вкладка, подсветка GLSL, ошибки от компилятора
  шейдеров движка; сохранение перезагружает шейдер (см.
  [рендер](rendering.ru.md)).

## Открытый вопрос

- Виджет текста: готовый (ImGuiColorTextEdit, MIT) или свой поверх
  `TextDocument`. Решается, когда дойдёт до работы.
