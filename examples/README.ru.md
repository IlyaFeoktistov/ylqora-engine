# Примеры

[English version](README.md)

`scripts/` - модуль игры со скриптами-примерами, собирается вместе с
репозиторием (`YQLORA_BUILD_EXAMPLES`, включено по умолчанию):

- `Rotator` вращает свой узел вокруг оси; его поля (скорость с пределами,
  ось) видны в инспекторе.

Он собирается через `yqlora_add_game_module`, по тем же правилам, что
проект получает через SDK, и его загружают тесты. Чтобы взять пример в
проект, скопируйте его файл куда угодно в проект: редактор собирает там
каждый `.cpp`, а скрипт регистрирует себя сам (`YQLORA_REGISTER_SCRIPT`; см.
[первый скрипт](../docs/guide/first-script.ru.md)).
