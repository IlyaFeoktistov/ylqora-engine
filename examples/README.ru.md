# Примеры

[English version](README.md)

`scripts/` - модуль игры со скриптами-примерами, собирается вместе с
репозиторием (`YQLORA_BUILD_EXAMPLES`, включено по умолчанию):

- `Rotator` вращает свой узел вокруг оси; его поля (скорость с пределами,
  ось) видны в инспекторе.

Библиотека названа как библиотека игры проекта (`game.dll`, `libgame.so`) и
лежит в `build/<пресет>/examples/scripts/`. Чтобы попробовать, скопируйте её
в папку `.build/` проекта и откройте проект в редакторе: скрипты появятся в
группе "Скрипты" в "Добавить компонент". В шаге 3 редактор собирает скрипты
проекта сам.
